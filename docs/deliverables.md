# 納品成果物設計

KEY CRAFT 5000 のB型向け成果物は、作業報告書ではなく納品先が受け取れるデジタル商品とする。

## 現在地成果物

- 現在地の町MAP（PNG / SVG）
- 現在地の街イラスト（PNG / SVG）

各成果物はプレイヤーの現在のDISTRICTと完成CRAFT数を反映する。未完成CRAFTは薄く表示され、MISSION完了ごとに建物・施設が追加されて街が成長する。

## 安定性方針

外部の画像生成AI/APIには依存しない。既存のMISSION、CRAFT種別、座標、進捗データからブラウザ内でSVGを決定論的に生成し、PNGへの変換もブラウザ内で行う。これにより生成待ち、API失敗、画像URL失効などを避ける。
